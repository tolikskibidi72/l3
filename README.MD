# Структура проєкту
* `t1.py` — сценарії обробки виключень (`try/except/else/finally`, перехоплення кількох типів, контекстний менеджер `with`).
* `t2.py` — ієрархія власних виключень (`ConfigError` та підкласи), ланцюжки `raise ... from` і повторне піднесення.
* `config_manager/` — структурований пакет із підпакетами `core` (`exceptions.py`, `validator.py`) та `utils` (`loader.py`, `logger.py`), налаштованим `__all__` і точкою входу `__main__.py`.
* `t4.py` — демонстрація інтроспекції (`__name__`, `__doc__`, `__annotations__`, `help()`).
* `requirements.txt` — список залежностей (використано лише стандартну бібліотеку Python).
